# 期货全品种活跃合约仓位、风险与资金管理系统 (PositionSizing)

基于工业级数学物理模型、凯利公式（Kelly Criterion）、多级产业链聚类防火墙与动态回撤断路器的量化期货多品种自适应仓位测算系统。

---

## 核心特性

1. **五层量化仓位与凯利公式 (Kelly Criterion)**：
   - 依据胜率 $p$、盈亏比 $b$、大数定律优势 $E = p \cdot b - (1 - p)$，结合分数凯利系数（默认 0.20x）实时推导组合安全开放风险预算与资金占用软硬上限。
   - 胜率过低或期望 $E \le 0$ 时自动触发无统计优势保护，严格归零仓位。

2. **6 组多情景压力矩阵优化与削峰填谷**：
   - 全局求解 $(p_{\min}, b_{\min}), (p_{\min}, b_{\max}), (p_{\text{mid}}, b_{\min}), (p_{\text{mid}}, b_{\max}), (p_{\max}, b_{\min}), (p_{\max}, b_{\max})$ 矩阵并求算术均值，实现自适应平滑建仓。

3. **产业链机制聚类防火墙 (Cluster Risk Firewalls)**：
   - 将国内主力期货品种划分为黑色建材、贵金属、有色金属、能化、农产品油脂、新能源与航运创新链等产业集群。
   - 单一产业暴露严格锁定在 25%~30% 预算之内，杜绝同源黑天鹅穿透账户。

4. **开仓受阻与加仓瓶颈诊断引擎 (Crowding-out Diagnostics)**：
   - 品种若被同集群高权重资产挤出或触碰风控硬顶，前端通过 **Toast 浮动气泡** 与 **公式推导模态框** 精准展示受阻成因与解除方案。

5. **实盘动态断路器防护与 4 大极端情景压力测试**：
   - 交易所统一调保 +30% 压力测试；
   - 全品种黑天鹅同向跳空 (2.0×ATR) 测试；
   - 黑色+建材产业链共振冲击测试；
   - **动态 10 连败生存测试**：随用户配置胜率与组合真实敞口动态计算 10 连败概率，并演示多级断路器（3%~10% 回撤熔断）受控残值与无保护纯复利衰减对比。

6. **天勤量化 (TqSdk) 实盘行情无缝联动**：
   - 自动获取主力合约最新昨收价（pre_close）、真实结算日、保证金率与波动率，离线时智能降级至高性能本地持久化缓存。

## 快速上手

### 1. 环境准备与依赖安装
推荐使用 Python 3.10+：
```bash
pip install -r requirements.txt
```

### 2. 配置天勤量化凭据 (可选)
复制配置模板并填写您的天勤量化账号：
```bash
cp .env.example .env
# 编辑 .env 填入 TQ_ACCOUNT 与 TQ_PASSWORD
```
*(若未配置天勤账号，系统将自动使用内置最新主力合约行情缓存正常运行)*

### 3. 启动本地服务
```bash
python run.py
```
启动后访问：
- **Web 仪表盘**: [http://127.0.0.1:8000](http://127.0.0.1:8000)
- **FastAPI 交互式接口文档**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

### 4. 运行自动化测试
```bash
python -m unittest discover tests
```
